# Add-on examples

- `crm-demo/` — HTML views in every place: a sidebar tab (`ui/dashboard.html`), a card in the conversation's info
  panel (`ui/card.html`), a modal form (`ui/order.html`) opened by an action; a CommonJS helper (`lib/format.js`).

Package one: `scripts/pack-addon.sh examples/addons/crm-demo` → `crm-demo-1.0.0.zip`, then
Settings › Nâng cao › Add-on › **Cài từ tệp .zip…**. Reference: `docs/addons.md`.
