## Applied

- **Tạo bình chọn:** title icon; uppercase section labels with a question counter (n/max); option fields with a
  leading radio/checkbox mark (follows "Chọn nhiều phương án") and a hover delete; a dashed full-width "Thêm lựa chọn"
  row and "Có thể thêm N lựa chọn nữa"; the settings are always visible as grouped rows (icon tile, title,
  description, switch) instead of a collapsed "Thiết lập nâng cao"; the anonymous options in their own group.
- **Bình chọn:** setting chips under the question; a summary row "N người đã bình chọn · Xem chi tiết ›"; options
  with %, vote count and up to three voter faces (they open the voter list); the same dashed "Thêm lựa chọn" row.
- **Chi tiết bình chọn:** one section per option with a "N phiếu" pill, 44px voter rows, "Bạn" pill.
