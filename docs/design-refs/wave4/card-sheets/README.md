## Applied

- **Đặt tên gợi nhớ:** a person row (avatar, name, the official sentence), a blue privacy callout, a labelled field
  with the counter on the label row and an inline clear button, and a hint when an empty field removes the alias.
- **Thông tin nhóm / cộng đồng:** a primary-colour cover band with the group avatar overlapping it, chips
  (members · Nhóm/Cộng đồng · creator), the description in a soft box, member faces + "A, B và N người khác" above
  the list, a "Trưởng/phó nhóm" pill instead of a key glyph, and "Tham gia nhóm / cộng đồng".
- **Bộ sticker:** the icon, title and "N sticker" in the header, a "Bấm vào một sticker để gửi…" hint, cells that
  grow slightly on hover.
